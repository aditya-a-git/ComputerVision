# Reproducing the experiments

Follow the preparation, training, validation and comparison commands in README. The demonstration uses seed 42, eight epochs, a batch of eight, CPU and YOLO11n at 320 pixels. It uses 100 annotated-or-negative training images and 24 disjoint validation images. Splits are inherited from the export. Drive-level independence is unknown. The best epoch uses validation feedback, so these results are exploratory validation measurements.

scripts.evaluate uses Ultralytics validation on the reserved split. scripts.compare verifies the selected image hashes, constructs a Hugging Face experiment manifest and runs seven pipelines on the identical ordered images. Darkness intensity is 0.65. Both RGB views have the same pixel coordinates. The secondary pass uses a grayscale CLAHE transform. A brightness, contrast and Laplacian-variance heuristic weights each view. Fusion greedily pairs highest-IoU same-class boxes at IoU ≥ 0.5, uses reliability times detection score for coordinates, and discounts scores for unmatched evidence. The proxy shares its input and trained detector with RGB.

The comparison keeps scores from 0.001, sorts per class, matches at most one detection to each annotation per image and IoU threshold, then averages interpolated precision at 101 recall points. mAP averages classes with annotations and uses ten IoU thresholds from 0.50 to 0.95. Precision, recall, F1, FP and FN use score ≥ 0.25 at IoU 0.50. This simple evaluator does not support crowd regions. Ultralytics and paired-comparison values can differ with resolution, preprocessing, confidence filtering and AP implementation.

After one warm-up call, each timed comparison frame includes local image decoding, the specified transform, reliability processing, executed detector branches and fusion. Exports, charting, UI and disk write time are excluded. FPS is processed frames divided by measured total seconds. Per-frame latencies, provenance and hashes are in report.json. App frame timings cover the selected pipeline on an already decoded image. Temperature and stream health are simulated.

The saved measurement folder includes the actual validation report, CSV summary, trainer history, acquisition manifest and native Ultralytics result. New runs use a fresh timestamped directory under runs/comparisons. Small sample size, class imbalance and weak localization limit inference about relative model quality.
